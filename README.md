# AlroyceCargo

This project is a Parcel Booking System (PBS) built using HTML,CSS, JAVASCRIPT and MYSQL as the database. The web application is designed to help Cargo Booking, which is to keep a track of booked parcels & manage and track packages more efficiently, reducing paperwork and increasing operational efficiency.

**Features**

Admin Login
* Admin can log in to manage the system and handle Bookings.
* Admin has the ability to view all Booking details, including sender, receiver, package details, and payment information.

User Login/Registration:

* Users can register an account and log in to track the status of their packages.
* Users can enter their information for delivery and get updates on their package.

Booking Management:

* The system allows the book parcel either PAID and TO PAY also TRIP SHEET
* Users can enter the tracking ID/LR Number to check the current status of their delivery.

Package Tracking:

* Users and admin can track the package in real-time by using the unique tracking ID.
* The status of the package is updated and can be accessed instantly.

Billing System:

* The system generates a bill for each package, including delivery charges and other details.
* The bill is automatically created when an order is placed, and users can access it through the system.



Technologies Used

* Python: The programming language used for building the backend of the system.
* SQLite3: A lightweight relational database management system used to store the data.
